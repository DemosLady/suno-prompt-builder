# 🎛️ Suno Prompt Builder

Build perfect **Suno AI** music prompts with an interactive production suite.

🔗 **Live:** [demoslady.github.io/suno-prompt-builder](https://demoslady.github.io/suno-prompt-builder/)

## Features

- 🎵 **13 Genres** with sub-genres (K-Hip-Hop, K-Pop, K-R&B, Traditional Korean, Electronic, and more)
- 🎭 **12 Moods** with auto-generated sonic descriptors
- 🎹 **70+ Instruments** including traditional Korean (Gayageum, Haegeum, Janggu, Daegeum, Piri)
- 🎤 **21 Vocal Styles** from aggressive rap to emotional ballad singing
- 📐 **8 Song Structures** (Standard, Hip-Hop, K-Pop, Ballad, Build-up, Cinematic, Freestyle, Anthem)
- 🎚️ **22 Production FX** (reverb, lo-fi, distortion, 808 glide, and more)
- ⚡ **8 Quick Presets** (Agust D Style, Spring Day Vibes, IDOL Energy, mono. Aesthetic, and more)
- ⏱️ **Tempo & Energy** sliders for fine-tuning
- 🇰🇷 **Korean Vocal Delivery** toggle — optimized for authentic Suno output
- 📋 **Style / Full** prompt modes with character counter
- 📜 **Prompt History** — saves your last 20 copied prompts

## How to Use

1. Pick a **preset** or build from scratch
2. Select **genre**, **mood**, **vocals**, **instruments**
3. Adjust **tempo**, **energy**, **structure**, **FX**
4. Copy the generated prompt → paste into Suno AI
5. Write your lyrics in Korean for best results! 🇰🇷

## Pro Tips

- Strip prompts to instruments/voices/beat essentials — less is more
- All lyrics in Korean for authentic Suno vocal delivery
- "K-hip-hop vocal delivery" + "native Korean pronunciation" = magic combo
- Put the most important style element FIRST in your prompt
